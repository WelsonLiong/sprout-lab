# Sprout Lab · SCES3274

An English Year 4 Science learning website about photosynthesis, prepared as a digital learning resource for SCES3274 Task 1. The pupil journey has six stops: a plant mystery, a leaf story, a condition lab, a creek rescue, Nico's forest adventure and a reflection. The forest is unscored; completing it unlocks a named PDF certificate without marks.

## Run locally

Serve the `dist` folder over HTTP, for example:

```powershell
python -m http.server 4174 --directory dist
```

Open `http://localhost:4174`. The JavaScript modules need HTTP; opening `index.html` directly as `file://` is unsupported. `dist/offline.html` is a printable alternative.

## Teaching scope

The resource addresses KSSR Science Year 4 learning standards 4.2.1–4.2.4. Pupils predict, manipulate simplified models, explain observations and revisit decisions after feedback. The teacher page maps each activity to the Science content and describes its meaningful learning design. Activity completion and the certificate are participation evidence, not official DSKP performance levels.

The SCES3274 brief also requires a 300-word design rationale alongside the resource. Prepare that written submission with the required course cover details and APA 7 references. The site itself does not collect those personal details.

## Access and provenance

The site has no pupil accounts, analytics, backend or externally hosted script. Nicknames and progress stay in browser storage. Controls support keyboard and touch input; captions, optional read-aloud, reduced motion and a printable trail are available. The forest needs WebGL 2. Source and asset acknowledgements appear on the site's Sources & safety page.

Nico is a supplied third-party model whose creator and license were not identified in the source assets. Verify redistribution rights before publishing this repository publicly. The bundled nature models, fonts and Three.js each retain their license files.
